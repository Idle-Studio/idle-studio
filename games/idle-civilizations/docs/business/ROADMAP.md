# Release Roadmap

## Version 1.0 — Foundation (Month 1–3)

### Milestone 1.0 Scope
**Core Engine:**
- [ ] Resource generation engine (tick-based, 1s intervals)
- [ ] Offline income calculation
- [ ] Building purchase and upgrade system
- [ ] Prestige / era advance system
- [ ] BigDecimal number formatting (1K → 1T → 1Qa → scientific)

**Content — 4 Eras at launch:**
- [ ] Stone Age (5 buildings, 2 resources)
- [ ] Bronze Age (6 buildings, 3 resources)
- [ ] Classical Empire (7 buildings, 4 resources)
- [ ] Medieval Kingdom (8 buildings, 4 resources, 2 Wonders)

**UI & UX:**
- [ ] Main gameplay screen
- [ ] Era transition screen with celebration animation
- [ ] Prestige screen with Legacy Token display
- [ ] Shop screen (IAP + coin store)
- [ ] Settings screen

**Services:**
- [ ] StoreKit 2 IAP (all products configured)
- [ ] AdMob integration (rewarded + interstitial)
- [ ] Game Center (leaderboard + achievements)
- [ ] Push notifications (local, scheduled)
- [ ] Firebase Analytics

**Infrastructure:**
- [ ] Remote config (Firebase) for content updates without App Store review
- [ ] CloudKit sync for save data across devices
- [ ] Crash reporting (Firebase Crashlytics)
